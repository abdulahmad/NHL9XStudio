# NHL9X Studio — agent handoff

## Status (2026-10-28)

Everything below is merged to `main` and live on GitHub Pages (a deploy can fail at the gh-pages push with an Internal Server Error: re-run the workflow).

- **96G:** NHL 96 Genesis is a studio profile (`nhl96`): 95-style sprite records, `frames96.asm` SPA names, extractAssets96.js pictures. SetSframe menu `*Sprites` and ArenaAnim/CupCelebration are frame banks (frame 0 included). Team logos stamp `TeamLogoPalettes` (`$1D93C8`). Team CRAM pals are `data/pals/genesis96`. Sound test stays off until `data/fixtures/nhl96-sound-slice.bin` is extracted.
- **96PC:** NHL 96 PC is a studio profile (`nhl96pc`). Names come from NHL96PC `HOCKEY.EXE` (`data/pc96-files.json`, SHA-1 `426fb8c0c80088c6a2c56a9dac50509cb9c24540`), not EA-NHL-Tools. Pictures are SHPI `.FSH` and locatebig C0 FB `.VIV` packs (`GAMEART.VIV`, …). Images list `DATA` then `GERMAN`, each VIV as a folder, and each FSH or REF as one item (SHPI tags in the filmstrip). Player sprites are `GAMEART.VIV` `total.ref` / `fight.ref` / `cup.ref` (`sub_61F2E` / `sub_622CD`; packed 10 FB after the 16-byte header is the raw pixel buffer, and `sub_AF85C` skips a Copyright prefix). Only `!` / `pal*` tags are palettes (the global 0x22-as-palette pass is reverted). Ice and ARENAART borrow `rinkpal.qfs` (`sub_B3420`). ICELOGO keeps each FSH in-file `!pal` (`sub_25E4D` locateshape `icelogo` — not newpal). Calendar day-box logos are `SETLOGO.REF` team tags (`sub_1B05E`) with `PNT.FSH` `!lgo` (`sub_1B6BC`); `CALNDxx.FSH` is the month `bkgd` and `CALBUTT.FSH` holds `DK%02d` chrome. AWARDS team logos use `newpal.qfs` (`off_11BB4C`). `BASEFILE.VIV/intro.fsh` `nhlp` uses `!pl1`; other intro images keep `!pl0`. `setlogo.ref` is one Images item. Songs are 1SNh wrapping an EACS header: `EACS+0x0B` is the voice slot, `EACS+0x0A==2` is EA IMA ADPCM (`sub_D57B4` / `sub_D585C`), `EACS+8` is bits and `EACS+9` is channels. Compressed 1SNh/1SNd payloads start with a 20-byte IMA block (`loc_CC55E`); 1SNl+8 is the loop jump in samples. 1SNh size includes the header; 1SNd size includes its 8-byte id; padding past those sizes is not decoded. Jerseys come from `newpal.qfs`. SPA is `unk_117A9C` (`tools/extract-pc96-spa.js` → `frames96pc.asm`): flags, pair count, `(frame, time)`, facing added to the frame. Copy the install into `pc96/` (`NHL_PC96_DIR`), or put the PC CD at `roms/nhl96.iso`.
- **95/96 PC ISO:** `roms/nhl95.iso` and `roms/nhl96.iso` (also `nhl95pc.iso` / `nhl96pc.iso`) catalog through ISO 9660 (`lib/iso9660.js`). A dropped `.iso` does the same in the browser. The extracted `pc95/` / `pc96/` folders still win when they have files.
- **Images:** NHLPA 93 SNES and NHL 94 SNES list the same groups and labels as 93 Genesis (screens, ice, fonts, sprites), with the source file names, the face-off, zamboni and crowd sprites (93S), and team palettes on the rinks and sprites. NHL 94 SNES gained Face Off, Team Blocks, EASN, Refs, Refs 2, Big Font, Small Font, Face Off sprites and Zamboni, and reads its own `RinkPalette` from the ROM (`snes.rinkPalette`). The static site reads the 93S rink palette from `data/pals/snes/Rink.snespal` (before, the pictures were grey there). Zoom goes to 30x.
- **Audio:** the four headings (Songs, SFX, Samples, Instruments) come from `lib/audio/categories.js`. 93S songs are listed by in-game cue, `N · SngName` (`lib/audio/nhl93-names.js`, `data/audio/nhl93s-sound.json`, regenerated by `tools/extract-nhl93s-sound.js`). Samples and instruments play and show their General MIDI mapping. 94G names its shared songs by equate.
- **Tests:** `node test.js` takes about 7 minutes. The 94S picture tests need the NHL 94 SNES ROM in `/tmp/snes/94` (the NHL94SNES folder; any file name, found by SHA-1 through `lib/upstream-rom.js`; the old `lst/nhl94snes.sfc` still works), otherwise they are skipped. The other disassembly ROMs are found the same way in `/tmp/disasm/<repo>` and `/tmp/snes/93`.
- **Open:** the 93S framer art is a two-shade ring while 93G's is a four-shade bevel (unresolved); the 93G/93S Stanley Cup palette was reported wrong but not reproduced (ask what colour is expected); the Crowd frames are sparse specks in both games (checked, not a bug).
- **Sync 2026-10-28:** the disassembly repos now keep the retail ROM in the repo folder under any file name (each repo's `tools/roms.js` finds it by SHA-1 and size; `lst/` is gone), build with `node tools/build.js` and generate the licensed player names and team nicknames from your ROM, so their `src/` has placeholders. Studio follows: `lib/upstream-rom.js` finds the ROM in an upstream folder by content; `data/frames93/94/95.asm` and `frames93snes.asm` are refreshed (comment cleanups); `nhl94s-sound.json` and `nhl94s-sound-analysis.json` use the new `SongNYICharge` label (was `SongIslandersCharge`).
- After source repos change, regenerate nhl-disasm-report (`python3 tools/generate.py`) and fix `lib/games.js` offsets if a layout moves.

## Where to work

Work only in **NHL9XStudio**. Push branches (`cursor/<name>-e6a9`), open PRs to `main`.

Do **not** commit `pc95` symlink or retail ROMs. Optional ROM paths for local tests are listed below.

**Releases:** before merging user-visible work to `main`, increment `package.json` and prepend `public/changelog.json` (same version, what changed). That is the About window's changelog and is what reopens the pop-up. Do not merge without it; see AGENTS.md.

Bundled regression fixtures live in `test/fixtures/` (ANIM/JIM/PAL). Full golden tests run without any external repo checkout.
