How the numbers work

Frame is the picture number: 1-based in the Genesis and SNES ANIM files, 0-based on PC like the game's own index. The index is always 0-based.

SPF names a run of those pictures in frames.asm. When the run is eight facings side by side, the compass steps through them.

SPA is an animation. Each of the eight facings has its own list of frame and vblank pairs. A negative time is the last step. The picture stays up for one extra vblank, the one that expires the counter, and never changes faster than every 4 vblanks. Bit 0 of the flags word loops it. Groups follows the sidebar categories. File is the order in frames.asm. Switching games stays on an SPA or SPF of the same name when the new game has one.

Images is the rest of the pictures in the ROM: titles, the rink, fonts, and the other animation banks. On GitHub Pages, use Open file… or drag a ROM onto the page. With node server.js locally you can also place files under roms/, pc95/, or pc94/.

Facing 0 is north on a vertical rink, then clockwise. A horizontal rink subtracts 2 from the facing before this lookup.

The dashed box is the frame's canvas. Pin chooses the point held in the middle of the stage. 0, 0 is the player's position, at the skates, and Hotspot is where the puck sits. The amber mark is 0, 0. The red cross is the hotspot.
